# 💻 Laptop Price Predictor

An AI-powered web application that predicts the estimated price of a laptop based on its specifications using **Machine Learning**.

## 🚀 Features

* Laptop brand selection
* Processor generation and type
* RAM and RAM type
* Storage and storage type
* GPU selection
* Operating system selection
* Machine Learning based price prediction
* Interactive Streamlit interface
* Professional responsive UI

## 🧠 Machine Learning

The project uses **Random Forest Regression** for laptop price prediction.

**Model Performance:**

* R² Score: 80.61%
* MAE: 14,507 PKR
* RMSE: 25,779 PKR

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* Random Forest Regression
* Joblib
* Streamlit
* HTML/CSS

## ▶️ Run Locally

Install the required libraries:

```bash
pip install -r requirements.txt
```

Run the Streamlit application:

```bash
streamlit run app.py
```

## 📌 Disclaimer

The predicted price is an estimated value generated by the trained Machine Learning model and may differ from actual market prices.
